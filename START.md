# За горизонт — сайт о путешествиях

Небольшой адаптивный сайт на React. Node.js запускает Vite — сервер разработки и сборщик. Отдельный сервер приложения и база данных не требуются.

## Запуск в Visual Studio Code

1. Установите **Node.js 24 LTS** (минимум 22.12) с сайта https://nodejs.org/. После установки перезапустите VS Code.
2. Откройте именно папку `MyNewRepo` через **Файл → Открыть папку**.
3. Откройте **Терминал → Создать терминал** и выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`). Терминал оставьте открытым. Остановка — `Ctrl+C`. После первой установки достаточно выполнять `npm run dev`. Изменения файлов отображаются автоматически.

Если порт занят, Vite выберет следующий свободный и выведет актуальный адрес. Для точного повторения установленных версий вместо `npm install` можно использовать `npm ci`.

## Страницы

- `/` — главная, поиск, подборка направлений, идея проекта.
- `/destinations` — шесть направлений, категории, поиск и подробное описание карточек.
- `/routes` — три маршрута с раскрывающейся программой по дням.
- `/about` — история и принципы проекта.
- `/contacts` — форма с проверкой имени, email, сообщения и обязательного флажка.
- Для неизвестных адресов предусмотрена страница 404.

Форма демонстрационная: данные не отправляются и не сохраняются. Проект не продаёт туры. Фотографии иллюстративные и не гарантируют соответствие географии карточек.

## Проверки и сборка

```sh
npm test
npm run build
npm run preview
```

`npm test` проверяет поиск и данные маршрутов. `npm run build` создаёт готовый сайт в `dist`. `npm run preview` позволяет проверить сборку локально, адрес будет в терминале.

Браузерные тесты (дополнительно):

```sh
npx playwright install chromium
npm run test:e2e
```

Проверяются пять страниц, навигация, поиск, фильтры, описание направления, программа маршрута, форма и мобильная версия. Тесты сами запускают сервер. В Linux можно использовать уже установленный Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`.

При размещении `dist` на хостинге настройте перенаправление неизвестных путей на `index.html`, чтобы прямые ссылки на страницы работали. Для локального запуска Vite делает это автоматически.

## Структура

```text
public/
  images/              Локальные фотографии
  favicon.svg          Значок сайта
src/
  main.jsx             Точка входа
  App.jsx              Навигация и маршрутизация
  pages/               Пять отдельных страниц
  components/          Общие элементы интерфейса
  data.js              Направления, маршруты и поиск
  styles.css           Оформление, адаптивность и анимации
tests/
  data.test.js         Проверки данных
  site.spec.mjs        Браузерные проверки
index.html             HTML и метаданные
package.json           Зависимости и команды
package-lock.json      Зафиксированные версии
playwright.config.js   Настройки браузерных тестов
```

Менять названия и маршруты удобно в `src/data.js`, оформление — в `src/styles.css`, содержимое страниц — в `src/pages/`. Анимации учитывают системную настройку уменьшения движения. Фотографии и шрифт хранятся локально: после установки зависимостей сайт не требует внешних сервисов.

Источники материалов указаны в `ASSETS.md`. Исходный README репозитория сохранён.
