# Источники материалов

Фотографии используются как иллюстрации атмосферы, а не как географически точные снимки направлений.

- `mountains.jpg`, `ridge.jpg`, `valley.jpg` — фотографии из шаблона [Start Bootstrap Grayscale](https://github.com/StartBootstrap/startbootstrap-grayscale/tree/master/dist/assets/img), распространяемого по MIT. Исходные фотографии — Unsplash, как указано в README шаблона. Текст лицензии сохранён в `public/images/LICENSE-grayscale.txt`.
- `lake.png`, `forest.png`, `coast.png` — иллюстрации из публичного учебного проекта [Travel UI/UX](https://github.com/adrianhajdin/travel_ui_ux/tree/main/public). Исходные имена: `img-1.png`, `img-2.png`, `boat.png`. При коммерческой публикации замените эти учебные материалы своими фотографиями с подтверждёнными правами.
- Manrope — пакет `@fontsource/manrope`, SIL Open Font License, лицензия включена в пакет.
- Иконки — Lucide, ISC License, лицензия включена в пакет `lucide-react`.
- Логотип и favicon созданы для этого проекта.
